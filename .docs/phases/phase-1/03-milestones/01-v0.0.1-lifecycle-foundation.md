## 목표

OS process 없이 lifecycle state machine과 동시성 모델을 먼저 확정한다.

실제 HTTP server는 이 마일스톤에서 필요하지 않다.

이 단계에서 **네 개의 identity와 `acquire()` 계약을 확정**하지 않으면
이후 마일스톤에서 state machine을 다시 뜯어야 한다.

## Acceptance

핵심 테스트:

```text
1000 concurrent acquire()

↓

FakeRuntime.start_count == 1
```

추가 검증:

```text
all waiters completed
duplicate process == 0
deadlock == 0
lost waiter == 0
active_requests == 발급된 lease 수
모든 lease drop 후 active_requests == 0
```

stale event:

```text
StartCompleted(이전 operation_id)   → state 변화 없음
StopCompleted(이전 operation_id)    → state 변화 없음
RequestFinished(중복 lease_id)      → counter 변화 없음
```
